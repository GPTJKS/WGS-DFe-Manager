Web service para Download de NFCe

O XML das Notas Fiscais de Consumo Eletrônico (NFCe) autorizados pela SEF-SC ficarão disponíveis para download para os contabilistas de empresas catarinense.

A SEF-SC irá disponibilizar um serviço (Web Service) com a funcionalidade de download destes documentos para um determinado CNPJ/CPF informado. O Requisitante deverá ser identificado através do seu Certificado Digital e deverá também estar vinculado ao CNPJ/CPF informado.

Caso seja identificado algum problema crítico durante o período de testes, o serviço poderá ser encerrado.

Está página será utilizada para comunicar alterações importantes no serviço.

Datas importantes:
01-01-2027 - Lançamento da versão 1.0 em definitivo.
28-08-2026 - Suporte ao CNPJ Alfanumérico e Chaves de Acesso com CNPJ Alfanumérico. (não são necessárias alterações no software cliente).
15-04-2026 - Lançamento da versão 1.0 em regime de testes.
